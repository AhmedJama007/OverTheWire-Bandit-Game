# Linux Cheat Sheet

A quick reference for the Linux commands I use most. Every command is written as a pattern with placeholders, the same way a formula is written before you plug in the numbers. Fill in the blanks and run it.

## How to Read It

| Symbol | Meaning | Example |
| --- | --- | --- |
| `<name>` | Replace with your own value | `<file>` becomes `notes.txt` |
| `[name]` | Optional part, leave it out if you do not need it | `[options]` becomes `-a` or nothing |
