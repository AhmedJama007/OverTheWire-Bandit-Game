# OverTheWire: Bandit

A record of my progress through the OverTheWire Bandit wargame, covering Levels 1 to 20. This section documents the Linux command-line fundamentals and security concepts I practised along the way.

## Overview

[Bandit](https://overthewire.org/wargames/bandit/) is a beginner-friendly wargame from the OverTheWire community. Each level presents a challenge that must be solved using the command line. Completing it reveals the password needed to connect to the next level over SSH.

## Objective

I chose Bandit to build practical Linux skills through hands-on work rather than theory alone. The challenges required me to chain commands together, read documentation, and work through problems in a real terminal. These are the same habits I rely on when working with servers and data pipelines.

## Skills Developed

| Area | What I Practised |
| --- | --- |
| File Navigation | Absolute and relative paths, hidden files, and complex directory structures |
| Permissions and Ownership | The Unix `rwx` model, file ownership, and reading files with restricted access |
| Searching | Using `find` and `grep` to locate files by size, type, or permissions, and to match patterns in text |
| Data Processing | Filtering and extracting data from noisy files and binaries with `sort`, `uniq`, and `strings` |
| Encoding and Decoding | Identifying and decoding Base64, hexadecimal, and ROT13 from the command line |
| SSH and Networking | Establishing remote connections, managing keys, and understanding client-server interaction |

## Disclaimer

In keeping with the OverTheWire community guidelines, this documentation does not include passwords, flags, or direct solutions. It focuses on the concepts covered, the tools used, and what I took away from each challenge.
